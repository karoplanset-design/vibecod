# FORMA Studio

Adaptive editorial website for the architecture and interior studio FORMA.

## Local development

Node.js 22.13 or newer is required.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Routes

- `/`
- `/projects`
- `/studio`
- `/services`
- `/journal`
- `/contact`
- `/projects/riverside-apartment`

All production imagery is local and lives in `public/images/webp`. Site copy is sourced from `spec/site-content.json`.
